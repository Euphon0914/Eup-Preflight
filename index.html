BEFORE YOU START

使用前须知

BROWSER

用电脑上的 Chrome 或 Edge

检查和修复依赖浏览器的硬件编解码（WebCodecs）和本地文件存储。Safari、Firefox 没有完整测试过，打开时页面顶部会提示。

MOBILE

手机上只看结果

手机浏览器可以体检、看报告；但在手机上修复，实测画面可能偏色，大视频也容易中途失败。修复视频请用电脑。

FIRST RUN

第一次会慢几秒

第一次分析要加载约 32 MB 的处理组件，第一次识别文字要加载识别模型。都从本机读取，不联网，之后就快了。

RULES

规则从哪来

标“官方”的来自平台官方页面；标“经验值”的是平台没有公开、业内常用的数值；标“占位”的还没核实（TikTok 有部分规则是这样）。点开任意检查项可以看来源和核实日期。

PRIVACY

视频不离开你的电脑

这个网页没有服务器、不需要登录，所有处理都在你的浏览器里完成。

不上传。

不联网。

[01]LOCAL

本机处理，不上传

读取参数、识别文字、转码修复都在浏览器里完成，视频和图片不会发送到任何服务器。

[02]OFFLINE

不联网，没有统计

ffmpeg、文字识别模型等组件都随网页放在本地，打开后不会请求外部网站；没有统计、广告或追踪代码。

[03]STORAGE

存在哪里

最近导入的 5 个视频（合计不超过 3 GB）和处理结果存在这个浏览器的本地存储里，下次打开不用重新选文件；深浅色、语言等设置也只记在本机。

[04]DELETE

随时可以删掉

在「技术体检 › 历史」里逐条删除，或关掉“自动载入”；清除浏览器的网站数据会全部删除。删除只影响浏览器里的副本，不影响电脑上的原文件。
